# SwitchKeyboard

Приложение для macOS 13+ на Swift. Живёт в строке меню (`A⇄Я`) и меняет раскладку уже набранного текста по горячей клавише. Словаря, проверки орфографии и автоматического исправления нет.

```text
руддщ                 → hello
Ghbdtn^ rfr ltkf?      → Привет, как дела?
Ghbdtn рщц фку нщг     → Привет how are you
```

## Запуск

Готовое приложение после сборки: `dist/SwitchKeyboard.app`.

```sh
bash scripts/build-app.sh
ditto dist/SwitchKeyboard.app /Applications/SwitchKeyboard.app
open /Applications/SwitchKeyboard.app
```

В настройках приложения нажмите «Запросить разрешения» и включите **SwitchKeyboard** в двух разделах macOS: **Конфиденциальность и безопасность → Универсальный доступ** и **Мониторинг ввода**. Если система потребует перезапуск, завершите приложение через его меню и откройте снова. Разрешения выдаёт пользователь; приложение их не обходит.

Для постоянного использования установите `.app` в «Программы» перед выдачей разрешений и включением автозапуска. Перед обновлением завершите SwitchKeyboard через его меню. Сборка использует сертификат Apple Development из связки ключей и не требует скачивания пакетов. Это локальная сборка без нотариализации. Если сертификатов несколько, задайте `SWITCHKEYBOARD_SIGNING_IDENTITY` именем или отпечатком подходящего сертификата из `security find-identity -v -p codesigning`.

При переходе со старой подписи ad hoc нужно один раз заново выдать «Универсальный доступ» и «Мониторинг ввода». Удалите старую запись SwitchKeyboard в каждом из двух разделов, добавьте текущую копию из «Программ» кнопкой «+» и перезапустите приложение. При последующих обновлениях сохраняйте идентификатор приложения, подписанта и тип сертификата. Скрипт проверяет совместимость подписи с установленной копией.

Без сертификата можно собрать тестовую копию командой `bash scripts/build-app.sh --adhoc`: она появится в `dist/adhoc/SwitchKeyboard.app`. Для обновления установленной копии используйте обычную сборку.

## Использование

- Запуск при входе в macOS включается по умолчанию один раз. Приложение работает в строке меню без окна настроек и без значка в Dock. Открыть настройки можно через `A⇄Я → Настройки…`. При отсутствии разрешений фоновый запуск также не открывает окно; доступ выдаётся из настроек приложения.
- Переключатель «Запускать при входе в macOS» отключает или включает автозапуск через штатный `SMAppService`. Если macOS требует подтверждение, используйте кнопку «Открыть объекты входа…». Настройка показывает фактический статус системы; отключение пользователем не отменяется при следующем запуске. Автозапуск происходит после входа в аккаунт пользователя.

- Наберите фрагмент и отдельно нажмите и отпустите **левый Option**. Удерживание Option вместе с другой клавишей сохраняет обычное действие.
- Меняется весь недавний фрагмент, включая пробелы, максимум 1024 символа. Enter, Tab, Escape, навигация, клик, прокрутка, смена приложения и команды редактирования сбрасывают фрагмент.
- Переключение языка через Caps Lock, Control+Space, Control+Option+Space или Command+Space сохраняет фрагмент, если фокус остаётся в том же поле.
- Выделение имеет приоритет: выделите ранее написанный текст и нажмите ГК. Максимальный размер выделения — 16384 единицы UTF-16.
- Для назначения ГК откройте `A⇄Я → Настройки… → Изменить…`. Нажмите сочетание с ⌘/⌥/⌃/⇧ или отдельно нажмите и отпустите один левый/правый модификатор. Esc отменяет запись. Настройка сохраняется между запусками.
- Преобразование EN ↔ RU выполняется посимвольно с сохранением регистра. После замены системный язык ввода переключается на язык результата: `руддщ → hello` выбирает EN, `ghbdtn → привет` выбирает RU. В смешанном фрагменте используется язык последнего преобразованного слова; конечные знаки, цифры и emoji не влияют на выбор. Например, `Ghbdtn рщц фку нщг → Привет how are you` выбирает EN.
- Нужный EN/RU источник должен быть добавлен в настройках клавиатуры macOS. Приложение выбирает последний использованный включённый источник нужного языка. Если такого источника нет, текст преобразуется, а в настройках приложения появляется пояснение.

## Совместимость и скорость

Перехват клавиш работает в отдельном потоке. Запросы Accessibility выполняются в другой очереди; искусственных пауз и таймера ожидания ГК нет. Левый Option срабатывает при отпускании. Фактическая скорость зависит от macOS и редактора; абсолютную нулевую задержку гарантировать нельзя.

В стандартных текстовых полях приложение проверяет текст перед курсором через Accessibility, затем отправляет Shift+Left и Unicode-вставку одним пакетом клавиатурных событий. Выделение через AX не изменяется: некоторые веб-редакторы применяют его асинхронно, из-за чего прежней версии требовалось два нажатия ГК. При расхождении с буфером замена отменяется. Для текстовых полей без AX-диапазона, но с доступной проверкой выделения, используется резервное удаление недавнего ввода через Backspace. Ошибка или таймаут чтения выделения отменяют замену. Резервный режим зависит от поведения редактора и его автозамен. Буфер обмена не используется.

Поля пароля, Secure Input и элементы без доступного текстового фокуса не поддерживаются. Некоторые игры, удалённые рабочие столы, нестандартные редакторы и терминальные программы могут игнорировать синтетический ввод. Работа во всех приложениях не гарантируется; совместимость проверяйте в нужных вам программах.

Пунктуация неоднозначна без словаря: `, . ; ' [ ]` могут быть знаками или ошибочно набранными русскими буквами. Приложение сохраняет эти знаки в конце слова и сохраняет парные разделители. Сразу после латинского текста символы верхнего ряда переводятся из ABC в стандартную русскую раскладку macOS: например, `^` становится запятой, `&` — точкой, `%` — двоеточием. `?` и проценты после чисел сохраняются. Строго обратимое физическое соответствие для буквенных клавиш доступно в ядре как `.physicalKeys`, но не включено в интерфейсе.

Набранный фрагмент находится только в оперативной памяти. Текст не записывается в файлы, логи или сеть; сохраняются только настройки приложения.

## Разработка и проверки

```sh
# Для XCTest нужен полный Xcode. xcode-select менять не требуется.
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
export CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache"
export SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/ModuleCache"
xcrun swift test --disable-sandbox --cache-path "$PWD/.build/swiftpm-cache"
```

`Sources/SwitchKeyboardCore` содержит преобразователь, буфер, выбор языка результата и автомат горячей клавиши без AppKit. `Sources/SwitchKeyboard` содержит интерфейс, системный перехват, замену текста и переключение источника ввода через TIS. `Tests/SwitchKeyboardCoreTests` проверяет три примера, язык результата, алфавит/регистр, пунктуацию, Unicode, границы буфера и поведение ГК. `Tests/SwitchKeyboardSystemTests` проверяет повторную трансляцию отложенных клавиш через системные таблицы EN/RU, Shift/Caps Lock и исключение служебных сочетаний. Системные тесты не переключают язык; при отсутствии стандартного включённого источника соответствующая проверка пропускается.

Проверка ядра не подтверждает работу системного ввода. Для сквозной проверки после выдачи разрешений: TextEdit, браузерное поле, Electron-редактор и Terminal; каждый из трёх примеров, повторная ГК, выделение, переназначение, Option+буква, Backspace, смена языка и курсора, быстрое продолжение печати.

На 10 ноября 2026: release-сборка 1.2.0 и проверка подписи успешны; 60 XCTest прошли без пропусков, включая таблицы EN/RU, управление автозапуском с подменённой службой и распознавание фонового старта. Установленная в `/Applications/SwitchKeyboard.app` копия успешно зарегистрирована в macOS: фактический статус автозапуска — включён, в том числе после обновления приложения. Пользователь ранее подтвердил `руддщ → hello` с физическим левым Option в TextEdit, замену за одно нажатие в GPT и смену системного языка в обе стороны EN/RU с продолжением печати. Фактический старт после нового входа в macOS пока не проверен. Остальные приложения, сквозное переназначение и фактическая задержка также не проверены.
