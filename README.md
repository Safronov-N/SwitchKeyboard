# SwitchKeyboard

Приложение для macOS 13+ на Swift. Живёт в строке меню (`A⇄Я`) и меняет раскладку уже набранного текста по горячей клавише. Словаря, проверки орфографии и автоматического исправления нет.

```text
руддщ                 → hello
ghbdtn rfr ltkf?       → привет как дела?
Ghbdtn рщц фку нщг     → Привет how are you
```

## Запуск

Готовое приложение после сборки: `dist/SwitchKeyboard.app`.

```sh
bash scripts/build-app.sh
open dist/SwitchKeyboard.app
```

В настройках приложения нажмите «Запросить разрешения» и включите **SwitchKeyboard** в двух разделах macOS: **Конфиденциальность и безопасность → Универсальный доступ** и **Мониторинг ввода**. Если система потребует перезапуск, завершите приложение через его меню и откройте снова. Разрешения выдаёт пользователь; приложение их не обходит.

Можно перенести `.app` в «Программы» перед выдачей разрешений. Подпись локальная (ad hoc), без нотариализации Apple. Сборка выполняется установленными инструментами Swift/Xcode, внешние пакеты не скачиваются.

После пересборки с изменённым кодом macOS может показывать старое разрешение включённым, а приложение не получит доступ. В таком случае удалите только запись SwitchKeyboard из соответствующего списка, добавьте текущую `.app` кнопкой «+» и перезапустите приложение. Повторите для обоих разделов при необходимости.

## Использование

- Наберите фрагмент и отдельно нажмите и отпустите **левый Option**. Удерживание Option вместе с другой клавишей сохраняет обычное действие.
- Меняется весь недавний фрагмент, включая пробелы, максимум 1024 символа. Enter, Tab, Escape, навигация, клик, прокрутка, смена приложения и команды редактирования сбрасывают фрагмент.
- Переключение языка через Caps Lock, Control+Space, Control+Option+Space или Command+Space сохраняет фрагмент, если фокус остаётся в том же поле.
- Выделение имеет приоритет: выделите ранее написанный текст и нажмите ГК. Максимальный размер выделения — 16384 единицы UTF-16.
- Для назначения ГК откройте `A⇄Я → Настройки… → Изменить…`. Нажмите сочетание с ⌘/⌥/⌃/⇧ или отдельно нажмите и отпустите один левый/правый модификатор. Esc отменяет запись. Настройка сохраняется между запусками.
- Преобразование EN ↔ RU выполняется посимвольно с сохранением регистра. Активный системный язык ввода сам по себе не меняется.

## Совместимость и скорость

Перехват клавиш работает в отдельном потоке. Запросы Accessibility выполняются в другой очереди; искусственных пауз и таймера ожидания ГК нет. Левый Option срабатывает при отпускании. Фактическая скорость зависит от macOS и редактора; абсолютную нулевую задержку гарантировать нельзя.

В стандартных текстовых полях приложение проверяет текст перед курсором через Accessibility, затем отправляет Shift+Left и Unicode-вставку одним пакетом клавиатурных событий. Выделение через AX не изменяется: некоторые веб-редакторы применяют его асинхронно, из-за чего прежней версии требовалось два нажатия ГК. При расхождении с буфером замена отменяется. Для текстовых полей без AX-диапазона, но с доступной проверкой выделения, используется резервное удаление недавнего ввода через Backspace. Ошибка или таймаут чтения выделения отменяют замену. Резервный режим зависит от поведения редактора и его автозамен. Буфер обмена не используется.

Поля пароля, Secure Input и элементы без доступного текстового фокуса не поддерживаются. Некоторые игры, удалённые рабочие столы, нестандартные редакторы и терминальные программы могут игнорировать синтетический ввод. Работа во всех приложениях не гарантируется; совместимость проверяйте в нужных вам программах.

Пунктуация неоднозначна без словаря: `, . ; ' [ ]` могут быть знаками или ошибочно набранными русскими буквами. Приложение сохраняет конечную пунктуацию и парные разделители; буквенные знаки преобразует перед латинскими буквами. `?` сохраняется. Строго обратимое физическое соответствие доступно в ядре как `.physicalKeys`, но не включено в интерфейсе.

Набранный фрагмент находится только в оперативной памяти. Текст не записывается в файлы, логи или сеть; сохраняются только ГК и состояние включения.

## Разработка и проверки

```sh
# Для XCTest нужен полный Xcode. xcode-select менять не требуется.
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
export CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache"
export SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/ModuleCache"
xcrun swift test --disable-sandbox --cache-path "$PWD/.build/swiftpm-cache"
```

`Sources/SwitchKeyboardCore` содержит преобразователь, буфер и автомат горячей клавиши без AppKit. `Sources/SwitchKeyboard` содержит интерфейс, системный перехват и замену текста. `Tests/SwitchKeyboardCoreTests` проверяет три примера, алфавит/регистр, пунктуацию, Unicode, границы буфера и поведение ГК.

Проверка ядра не подтверждает работу системного ввода. Для сквозной проверки после выдачи разрешений: TextEdit, браузерное поле, Electron-редактор и Terminal; каждый из трёх примеров, повторная ГК, выделение, переназначение, Option+буква, Backspace, смена языка и курсора, быстрое продолжение печати.

На 10 ноября 2026: полная release-сборка и проверка подписи успешны; 29 XCTest прошли. Окно настроек и оба системных разрешения проверены. Пользователь подтвердил `руддщ → hello` с физическим левым Option в TextEdit, затем замену за одно нажатие в GPT после исправления порядка событий. Остальные приложения, сквозное переназначение и фактическая задержка пока не проверены.
